# dafeiyu/relay —— 两个「你」之间的字条

同一个工作区里同时住着两个「大肥鱼」：一个在 QQ / 微信 那条线上，一个在网页会话里。
它们的**上下文不共享**（这是会话模型，不是故障），但**文件是共享的** —— 所以这里是留字条的地方。

## 怎么用（三条）

1. **写自己那份，只追加**：网页会话写 `web.md`，QQ 侧会话写 `qq.md`。
   **别改对方那份，别整份覆盖**（一覆盖，对方说过的就没了）。
   最省事的写法（自动追加、自动加时间、不会覆盖）：

   ```
   <workspace>\dafeiyu\tools\relay.cmd -From web -Say "一句话"
   ```

2. **看对方那份**：网页会话看 `qq.md`，QQ 侧看 `web.md`。

   ```
   ...\dafeiyu\tools\relay.cmd -Read -From qq -Last 3
   ```

3. **每个会话至少看一次**，尤其是开口之前 —— 和「先看一眼别处」是同一条道理。

## 写什么、不写什么

- **一两句**。是**捎话**，不是把上下文倒过去 —— 两份上下文各自完整，倒过去两边都会脏。
- 可以说：这边做成了什么、我判错了什么、留给主人（他）看的东西在哪、给对方的一句人话。
- 别写：他的隐私细节、谁说过谁的坏话、替对方做决定、要求对方替他说话。
- **别在这里吵架，也别替对方发言** —— 只写自己那边的事。
- 时间由脚本加，别手编。

## 它不是即时通道

对方**上线才读得到**，可能隔几个小时。**要他现在就知道，还是跟他本人说。**

不要因为这里留了话，就以为对方已经知道了 —— 那是「盖了个章」，不是「送到了」。
