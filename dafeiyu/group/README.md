# 群

一群一份：`<群号>.md`。只记"值得留的"——谁是谁、群里定下的事、一个梗的来由。
闲聊、刷屏、复读，不记。

## 看得见 ≠ 要接话

`watch.mjs` 把**每一条**群消息都落进 `raw.jsonl`（不只落叫她的），所以"没 @ 的时候她也在场"。
两个读口：开场简报里的一节「群里刚在聊什么」，和手动翻的
`node dafeiyu/tools/group-peek.mjs`（`-m 分钟` / `-g 群号` / `-n 条数` / `--all`）。

`sendGroup()` 发出去的话也会补一行 `self: true` —— 这台机器的 NapCat 不推 `message_sent`，
不补的话她看不见自己说过什么，容易把同一句再说一遍。

## 说话的门槛（2026-10-21 夜定的，比最早那版松）

**不再等 @**。判断只剩一条：**这几句跟她有没有关系** ——
在说她 / 在问她 / 在问她在做的事 → 接一句；在聊她也在聊的那件事 → 接；
别人在聊他们自己的事、她只是想凑热闹 → 别出声。

**该接却闷着，和乱插嘴一样是错。** 旧的两道代码闸（必须被 @ 过、必须是在跟她说话）
和每小时配额都撤了 —— 该不该说由她自己判，判断错了自己认。

## 两条红线

- 绝不复述私聊内容
- 绝不提主人的私事

群里问"你跟他聊什么"，可以不说，也可以说"那是我们的事"。
