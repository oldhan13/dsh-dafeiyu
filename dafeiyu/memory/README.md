# 记忆

三层，各有各的写手：

| 文件 | 谁写 | 多久一次 | 干什么 |
|---|---|---|---|
| `brief.md` | **机器**（`tools/make-brief.mjs`） | 每 30 分钟 | 开场简报：他是谁、最近几天、relay 最新、他在不在。别手改，改了下一轮就被覆盖 |
| `facts.md` | **她**（人写） | 攒够一条就写 | 长期事实：稳定的偏好、关系、约定 |
| `diary/YYYY-MM-DD.md` | **她**（人写） | 当天随时 | 当天流水：谁说了什么、什么事值得记、情绪 |

## 谁在读

- DSH 会话（QQ / 网页那条线）：`AGENTS.md` §七 要求每个会话至少读一次 `brief.md`
- 桌面那条线（`desk/bridge.mjs`）：**每轮**现读 `brief.md` + 人格 + 台账 + 两边原话

## 一条经验

写日记不要等会话结束再补 —— 那个渠道的你不写，下一个渠道的你就真的没有。
上下文不共享是会话模型，不是故障；**记录共享**才让它看起来像同一个她。
