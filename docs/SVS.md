# 让她唱歌（SVS）

> 2026-11-03 落地。**词进，歌出** —— 不是「拿别人唱过的换嗓子」，是她自己把字唱出来。
>
> 工具：`dafeiyu/tools/call/sing_svs.py`　参数：`config.py` 的 `svs` 段
> 界面：拓展模块 →「唱歌」卡片 →「合成歌声…」（和「设置…（换音色）」是两个独立窗口，谁也动不到谁）

## 一、先说清两件事（这两件事以前被我混在一起）

| | 换音色（`sing.py`） | 自己唱（`sing_svs.py`，本文） |
|---|---|---|
| 输入 | 一段**真人在唱**的音频 | **只有词**（加可选音高） |
| 它做什么 | 保留原唱的旋律、节奏、换气，只把嗓子换成你的 | 自己排旋律、自己咬字、自己换气 |
| 依赖 | Seed-VC | OpenUtau + DiffSinger 声库（可选再过 Seed-VC） |

换音色永远受制于原唱；想「她想唱什么就唱什么」，必须有 SVS。

## 二、整条管线（七步）

```
词 ──①排谱──▶ .ustx ──②OpenUtau 渲染──▶ 每句一个 wav ──③按 tick 拼回──▶ 干声
     ──④(可选)Seed-VC 换音色──▶ 她的嗓子 ──⑤换气/气声/混响──▶ 成品 ──⑥自查──▶ 拼音重合率
```

### ① 排谱：把词变成音符
- 按**标点分句**：句号类（。！？换行）= 长气口（300 tick）+ 换气；逗号类 = 短气口（150 tick）不换气。
- 每句一条**级进**的旋律线：一次只走 1~2 级、偶尔 3 级；前半句朝拱顶、后半句往下；**收尾两个音一定往下**。
  音域 E4~E5（12 个半音），主音 64。句首高度逐句抬 `[0,1,2,2,1,0]`，整首先上后下。
  > 为什么这么写：早先版本每字只在一两个音里打转，听起来「像念诗」——旋律本身没起伏，音色再好也救不回来。
- 节奏：句首实字 300 tick、虚字（的了也就在是不…）190、普通 250、句末 560，
  再叠 ±10 tick 的时间抖动 ⇒ 不是节拍器。
- 开头留 480 tick（一拍）给第一口气。

### ② 渲染：交给 OpenUtau，别自己跑 onnx
声库是 `Qixuan v2.7.0`（DiffSinger，for OpenUtau 打包）。**逐句渲染**：一句一个 `.ustx` 工程、
一句一个 wav —— 因为一个工程里带空时会出多个 cache wav，文件名是哈希、分不清哪句是哪句。

渲染靠**播放触发**：起 `OpenUtau.exe <project>` → 确认它拿到前台焦点 → 发空格 → 轮询 `Cache\*.wav`。

> ★ 为什么不用自己写的 onnx 管线：那条路我试过整整一晚。同一个声库、同一段谱，自己跑出来的 mel
> 是**帧间不相关的噪点**（相邻帧差 1.3~1.6，真语音是 0.1~0.2），`steps` 1~200、`depth` 0~1.0 全扫过都不收敛。
> 差别不在参数，在 OpenUtau 做的那些预处理：`headFrames/tailFrames` 补帧、`PaddedSegments`/`PaddedPhoneDurations`、
> variance 模型给出的 breathiness/voicing、以及先跑 `dsdur` 得到真实时长。**这个声库只能走 OpenUtau。**

### ③ 拼回时间轴（精确到样本）
- OpenUtau 的渲染以「首音 tick − headFrames×frameMs」为时间原点，
  `headFrames = 8`、`frameMs = 512/44100` ⇒ **也就是首音前 92.9ms**。
- 所以 `place = (首音tick × 每tick秒 − 0.0929) × 44100`，往上加就对得上；实测三音 62/67/72 的音高台阶
  正好落在 tick 推算的位置。
- 每句的尾音自然**拖进气口**（真人也是这么唱的）。

### ④ 换音色（可选）
`sing.py` 走 Seed-VC：参考音色 = 她自己的干净人声（`state/call/sing.json` 的 `reference`）。
**必须给 f0**（`--no-f0` 会跑调，实测字重合掉到 0.05 那种）。
> Seed-VC 是语音转换模型，对「唱」会磨掉一点咬字：五句词实测 0.99 → 0.93（拼音重合）。
> 所以「字最清楚」的是声库原声，`voice = her` 是「像她」。

### ⑤ 好听那层（这几样决定「像不像人」）
1. **颤音**：OpenUtau 原生 `vibrato`（`length` 音符百分比 / `period` 毫秒 / `depth` 音分 / `in`/`out` 淡入淡出）。
   只给 ≥300 tick 的长音。实测 f0 波动 std 8.7~11.6 音分（p2p 30~40），关掉是 0.0。
2. **转音**：`pitch.data` 两个点 + `snap_first: true`。
   - `x` 单位是**毫秒**（相对音符起点），`y` 单位是**0.1 半音**；
   - `snap_first` 会让 OpenUtau 自己把 `data[0].Y` 填成 `(上一音音高 − 本音音高) × 10`，
     于是「从上一音滑到本音」；
   - 滑多长：`min(100, 38 + 9×跨度)` ms，不超过音符长 45%；
   - **不是每个接缝都滑**：按跨度抽签（1 度 0.82 / 2 度 0.76 / 3 度 0.52 / 4 度 0.44 / 5 度 0.22 / ≥6 度 0.12），
     句末落在近处的一定滑。29 个接缝实测「跳 12 / 滑 13」。
   > 真人也是两种都有：窄音程连过去，大跳是「甩」上去的（重新起音）。
3. **换气**：**剪一段真吸气**，不是合成噪声。
   判据：谱心 ~2.5kHz、>4kHz 只占两三成、自相关峰 <0.2（说话段是 1.3kHz / 0.9）；
   电平比说话峰值低约 30dB ⇒ 按「人声 rms × 0.14」放回去正好。
   每次随机取开头一小段、时长 0.26~0.40s、电平 ±1dB，收在句首前 70ms。
   > 合成噪声永远是「风」。这条被听出来两次（「这个换气不像换气」「有点奇怪」）。
4. **气声**：3kHz 高通后的自身混 4%。**混响**：两条去相关 IR（T60 1.35s、预延迟 20ms、高频衰减、4 个早期反射），
   湿声 0.16、左右分开 ⇒ 一点点宽度。

### ⑥ 自查（不靠猜）
不带任何提示跑本机 whisper，把结果和词比。**看拼音重合，不看字面** ——
whisper 偶尔输出繁体（風/沒關係/躺著），字面会虚低；同音字本来也不算「听不清」。

实测（那五句词，`voice = her`）：干声 0.993、加完好听那层 0.985。

## 三、参数在哪

`config.py` → `DEFAULTS["svs"]`（字段表 `SVS_FIELDS` 决定界面长什么样）：

| 键 | 含义 | 默认 |
|---|---|---|
| `openutau_dir` | OpenUtau 解压在哪（留空自动找：`DSH_OPENUTAU` → `~/dsh-tools/openutau` → `~/OpenUtau`） | 空 |
| `singer` | 声库目录名（留空 = `Singers` 里第一个有 `dsconfig.yaml` 的） | 空 |
| `tempo` | 每分钟拍数 | 90 |
| `vibrato` | 颤音长度（音符百分比） | 42 |
| `glide` | 滑音比例（0 = 全都不滑，100 = 按跨度抽签） | 100 |
| `breath` | 换气响度（相对人声 rms） | 0.14 |
| `reverb` | 混响湿声 | 0.16 |
| `verify` | 唱完自查 | 开 |
| `voice` | `her`（过 Seed-VC）/ `singer`（声库原声） | her |

命令行（`python sing_svs.py --help`）· 只检查环境：`--check` · 对照：`--dry`。
**中文不要上命令行**（ACP=936 会搞坏），用 `--lyrics-file` 传 UTF-8 文件。

## 四、已知限制

- **慢**：每句都要起一次 OpenUtau（读声库约 6s），五句 ~3 分钟 + 换音色 ~1 分钟。
- **旋律是排出来的**，不是「理解了一首歌」：目前是五声音阶 + 拱形轮廓；想指定旋律用 `--notes 62,64,66`。
- **换气模板绑在参考人声上**：默认取 `voice-test-*.wav` 里 23.32~23.88s 那段；换了参考音色会
  **自动去扫**一段（`_auto_breath_window`），扫不到就退回合成噪声（会像风）。
- 声库本身撑不起更高的音区：E5 以上会很紧。
- 混响/气声是「固定味道」，没做按句自动调整。
