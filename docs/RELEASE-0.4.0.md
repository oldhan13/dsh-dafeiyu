# v0.4.0 · 电话那头是她本人

> 2026-10-29。这一版几乎全在「说话」这条线上：**听得准、记得住、不卡**，外加一个唱歌的口子。
> 前两版（0.3.0 / 0.3.1）把通话接通了；这一版修的是接上之后**听着像不像同一个人**。

## 一、听得准：Whisper 会对着空气编话

跨虚拟声卡过来的音频窄带、有断点，whisper 遇到"安静但不像安静"的片段会**自己编一句中文**
（实测编出过「以下一张字」），于是她开始答一些根本没人说过的话 —— 听感就是"她有点傻"。

三道防线（`dafeiyu/tools/call/engine.py`）：

1. 整段能量太低（RMS < 0.012）**根本不送耳朵** —— 他正常说话在 0.04 以上；
2. 转写命中"字幕 / 请不吝点赞 / 感谢观看 / 本期视频 / 用简体中文书写"这类样本词 → 一律当没听见；
3. 噪声底允许往上爬，别把底噪当人声。

判据是"这句我有没有送进去"，不是"她答得像不像"。

## 二、记得住：上下文拼的是「人和说过的话」

**问题**：电话接通了，但对面听着像陌生人 —— 他原话「不知道我们之间的任何事」。
根因是先前的上下文只塞三样：自动生成的开场简报、技术台账、当天日记。三样全是**工作材料**：
它知道这个项目在干什么，却不知道你们俩之间发生过什么。

**改法**：新文件 `dafeiyu/tools/call/call_context.py`，只读文件、不联网、不调模型，约 20ms，拼五块：

| 块 | 来源 | 为什么是它 |
|---|---|---|
| 他是谁 | `people/<你的QQ>.md` | 关系、称呼、边界、记过的事 |
| 他最近说过什么 | 活动日志里的原话（带时间） | 我们这两天到底在聊什么 |
| 上一通电话 | `state/call/call-transcript.md` | 连续性 |
| 我自己写的 | 最近两篇日记 | 这部分才有"我"的味道 |
| 此刻在做什么 | 活跃台账尾巴 | 手上正做到哪 |

合计约 7k 字 ≈ 3.5k token。★ 载入失败自动退回旧逻辑 —— **不许因为一层新模块把电话弄哑**。
★ 调试：`python dafeiyu\tools\call\call_context.py` 直接看拼出来的样子。

## 三、别把自己叫错：名字得写进 prompt

他问过一句「为什么他现在还觉得他叫大肥鱼，而不是汐？」。查了：那段 `SYSTEM` **从头到尾没写过自己叫什么**，
而简报里唯一一个名字是「项目名是大肥鱼」—— 于是她把项目名当成自己的名字。

现在明写：你叫汐 / 旧名也叫得应 / 听到「我叫什么」要答汐；
并且写死「你和他不是客服和用户，**电话只是换了张嘴，不是另一个人**」「有记忆，不许说『我们刚认识』」。

## 四、不卡：抖动缓冲 + 分小句整句合成

原来"合成一块播一块"老卡。量完才发现问题不在平均速度 —— 整句 RTF 0.6（不慢），
但 sovits 的出块是**突发式**的：一句中间有 570~860ms 空档，播放端按 1.0 倍速放，缓冲一空就是一声卡。
**平均够快，节奏是错的。**

- `engine.py` 新增 `JitterPlayer`：生成与播放拆两条线，垫够 cushion 再开口，垫子自己会调；
- `tts.py` 发 `stream=0`：按小句**整句**合成，句内不再切块。

判据：`state/call/petcall.jsonl` 的 `starved`（true = 那一声卡）与 `cushion_s`。
⚠️ 别改回"拿到一块就 sink 一块" —— 那正是卡顿的来源。

## 五、唱个歌

`dafeiyu/tools/call/sing.py`：Seed-VC 音色转换 —— 拿一段清唱当样板，把另一首歌**唱成那个声音**
（调子、气口、换声都在，不是让 TTS 念歌词）。24 步、17.8 秒的歌，这台机器 48 秒出成品。
设置 `state/call/sing.json`；拓展模块里多了一张「唱歌」卡（挑样本 / 自检 / 跑一次）。
两个坑：`hf_utils` 要**本地优先**、`torchaudio.save` 写出来的 wav 是坏的（改走 `soundfile`）。

## 六、部署界面：两张新卡

「拓展模块…」里现在有：

- **语音通话** —— 音色（piper / sovits / cloud / openai）、耳朵模型、说话手感、一键装好、`试听这句`；
- **唱歌** —— 样板音、步数、自检、开控制台跑。

所有设置都走同一个真源 `dafeiyu/tools/call/config.py`（`--json` 出控件、`--set` 存盘），
**别在 ps1 里再抄一份后端表** —— 抄一次就多一个会说谎的地方。

## 七、群里那一半

- **按群放开**：`dafeiyu/group/permissions.json`，一个群一档 ——
  `strong`（不必等点名，强相关就接）/ `at`（真 @ 也由本机回，回之前先看主会话有没有回过）。
  照 `permissions.example.json` 抄；没写的群行为不变。
- **心跳读的是真消息**：用 `get_friend_msg_history` 问最近 20 条（日志只当兜底 ——
  它按 ~5MB 轮转、只盖几个小时），并补一句「你最后一条是 N 分钟前发的，人在，只是手不在键盘上」。

## 八、可移植性（别人从仓库下载那份也能跑）

- `GSV_ROOT` / `GSV_PYTHON` 不再写死：环境变量 → 常见位置 → 项目旁边，三级探测；
- TTS 输出目录改成相对 `state/call`；
- token 一律走 `%USERPROFILE%\.dsh\…`；QQ 号一律走 `DAFEIYU_OWNER_QQ` / `DAFEIYU_BOT_QQ`；
- NapCat 日志目录走 `DAFEIYU_NAPCAT_LOG_DIRS`（分号分隔）。

## 升级注意

- 拉完代码先跑一次部署界面 →「拓展模块…」→ 语音通话 → **检查一遍**（它会真的 import 那些包）。
- 判据仍是 `.venv\.deps-ok` 那个记号在不在，**光有 `.venv` 不算**。
- `state/call/config.json` **绝不能带 BOM**（带了对 JSON 解析就是废的，表现成"换了音色声音不变"）。
