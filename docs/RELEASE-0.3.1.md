## 打电话的她，现在知道你在干什么

上一版的电话只解决了「不卡」，这一版解决的是**她在那儿到底知道多少**。

真事：那天他问了一句电脑的情况，她答「我这儿看不到你电脑的情况呀」。
查下去才发现 —— **她的系统提示是空的**。电话里那个她，除了「正在打电话」以外什么都不知道：
不知道今天发生了什么，不知道眼前这个人是谁，也不知道现在几点。

现在每次开口之前都会带上两样东西：**开场简报**（最近几天、长期事实、群里刚在聊什么，≤1800 字）
和**当前时间**。她不再是刚上线的一张白纸。

## 她能动你的电脑了

不是给她开一堆工具 —— 电话里那 5 秒的延迟扛不住多轮工具调用。
做法是**把话转给桌面那条线**：她判断这句话要动手（开程序、截图、查内存、改文件），就只回一个记号 `[[电脑]]`；
引擎把这句原话交给桌面上那个一直在跑的 agent（工具、记忆、权限都是现成的），再把回答念出来。

- 实测一句「还有多少可用内存」：**5.3 秒**回来，答的是真数字（32G 里剩 11G / 65.7%）。
- 记号本身**永远不会被念出来**（返回前统一剥掉）。
- 转不动的时候（桌面那条线没起、超时）她会给一句实话，而不是硬猜。

代价是明确的：这类问题要等 5 秒出头，所以它只适合「帮我打开…」「看一眼…」，
闲聊走原来那条快路，不走这里。

## 动画不再一帧干一堆活

卡的不是帧率，是**每帧要干的活**：原来一帧要画 14 个圈，每个圈都调一次 PowerShell 函数、做几次类型转换 ——
解释这些代码比真正画还贵。

现在光环按「状态 × 脉冲 16 档」**提前画成小位图**存着，一帧只剩一次贴图；
三段文字用的矩形也只造一次。定时器保持 40ms（25 帧），没有靠降帧率来换顺。

⚠️ 一句实话：这一项我只量了「每帧少做多少事」，**没有真的开窗口量帧率**。好不好得看眼睛。

## 语气

提示词重写成「说人话」：长短错开、允许语气词和停顿、按对方的状态给软硬；
标点处的留白也从 80 / 160ms 放回 **115 / 210ms** —— 上一版为了「不卡」压得太赶，赶就显机械。

⚠️ 同上：语气只有提示词层面的依据，得他听着算。

## QQ：可以贴表情了

新增一条补丁 `emoji-reaction`：把 `set_msg_emoji_like` 加进 `dsh-onebot-qq` 的 action 白名单。
在这之前它不在白名单里，想贴只能绕开插件直连 NapCat 的 HTTP —— 那等于把端口和 token 签到别处去。

打完、重启 `dsh web` 之后：

```
qq_napcat_api(action: "set_msg_emoji_like",
              params: { message_id: "<消息 id>", emoji_id: "128077", set: true })
```

`128077` 是 👍，`set: false` 是取消。
边界写清楚：**自己发的消息**返回里就带着 `message_id`；**别人发来的消息目前拿不到 id**
（上游插件的入站边界里没传），要给他的那句话贴，还得再改入站那一侧。

补丁一共四个了（戳一戳 / 私聊分句 / 群消息镜像 / 表情回应），**装的时候自动打上**，
升级 `dsh-onebot-qq` 之后重跑一次 `node patches\apply-patches.mjs` 就回来。

## 怎么装 / 怎么升

```
git clone https://github.com/oldhan13/dsh-dafeiyu.git
cd dsh-dafeiyu
.\install.ps1
```

已经在用旧版的：配置界面右上角 **检查更新** → 更新到最新。
只换代码和文档，记忆、人物档案、图片、聊天历史、桌宠位置一样都不碰。

⚠️ 打完补丁要**重启 `dsh web`** 才生效（插件模块在宿主进程里有缓存，改磁盘 ≠ 改内存）；
通话窗也要重开一次才吃到新引擎。
